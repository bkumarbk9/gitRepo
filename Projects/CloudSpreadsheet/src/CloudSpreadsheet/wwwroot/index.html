Formula help
  • Cell formulas, as in Google Sheets: start with =, e.g. =B2*C2, =SUM(D2:D20), =IF(A2>10, "big", "small").
  • Column formulas: type Title=expression in a header cell (row 1), e.g. Total=Quantity*Price. Every row below is calculated from the columns named in the expression.
  • Operators: + - * / ^ %, & joins text, comparisons = <> < > <= >=.
  • Functions: SUM, AVERAGE, MIN, MAX, COUNT, ROUND, ABS, SQRT, POWER, MOD, INT, IF, LOG, LN, EXP, SIN, COS, TAN, PI.
  • Changes save automatically and appear live for everyone with the same sheet open. Share the link to collaborate.
  • After 30 minutes without use the page disconnects; click Reconnect to carry on where you left off.
